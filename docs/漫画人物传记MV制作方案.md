# 漫画人物传记 MV：通用制作方案

本方案总结自一次人物传记短视频协作，适合用已有图片、字幕和音乐制作短片。它是一套可调整的工作方法，不限定题材、时长、画幅、画风或工具。下面的 90 秒、16:9、无口播仅是本次项目的例子。

## 一、先对齐目标和权限

1. 确认观看对象、发布平台、时长、画幅、有无旁白，以及观众看完应记住的人物和故事。
2. 区分「讨论」「素材整理」「样片」「全片预览」「正式导出」：每阶段按用户已授权范围推进；对分镜、画风、结尾等关键选择保留明确确认。
3. 问清参考图是成品风格、待拆素材还是灵感参考。不要把拼图理解为最终镜头顺序，也不要因为参考视频的视觉风格覆盖用户选定的美术方向。
4. 了解预算和素材来源，优先复用已有素材与工具；独立图片是否可发布需结合实际授权和用途核对。

## 二、核对人物事实，确定叙事主线

- 以用户提供的资料为出发点，对关键年份、事件、因果关系、引语和人物职务变动查找可靠来源。信息随时间变化时重新核验并记录来源、日期和语境。
- 把研究结果分为「确认」「尚待核实」「创意演绎」，尤其不要把猜测、营销描述或漫画画面当成历史事实。
- 将经历提炼为几次能让观众理解的选择或转折，而非罗列产品和年份。无口播视频里，字幕承担事实，画面表达处境，音乐推动情绪。
- 实际字幕要短、可读、能承接前后因果；逐字引语注明发言人和必要语境，翻译或摘译明确标识。

## 三、整理素材与画风

1. 建立原始素材目录，保留原图；清点图片尺寸、来源、编号、内容、授权状态和可用范围。
2. 对拼接图按实际格线拆分；遇到跨格画面、贴边人物、字幕或空白背景时逐一判断。无损保存裁切结果，记录来源、坐标和编号；检查工具实际输出尺寸与索引一致。
3. 建立索引：素材编号、路径、内容、分辨率、原图来源、裁切位置、对应剧情、异常与待确认事项。保留未入片素材以备后用。
4. 先确认视觉母版（例如彩色漫画、水彩、墨线和纸张），再判断补图、清晰度修复或风格统一是否必要。用参考图指导新增视觉，但保留人物辨识度；AI 生成画面不得冒充现场照片或历史证据。
5. 对不同来源的人物图，检查构图、颜色、标识和风格是否一致。若需重绘，保留原件并保存新版本，说明生成内容；未经核对的标识、肖像和引用来源不要隐去其实际来源记录。

## 四、先做声画小样，再铺全片

- 先选 15–25 秒有起承转折的段落，写明镜头、字幕、动作、音乐情绪和切换时点。关键事件前可以停一拍，而不是持续堆特效。
- 做低成本可播放样片，先判断观众是否看懂故事，再看画风、字体、镜头、节奏和音乐。让用户用实际画面反馈，修改后再扩展全片。
- 字体保持统一；重点词可以分拍、刷痕或手写出现，普通信息清楚出现即可。短镜头要保证标题和说明文字有足够阅读时间，避免字幕相互遮挡。
- 动态由画面内容决定：电脑屏幕闪烁、机柜灯流动、芯片上的手绘线路、纸张和画框运动、人物轻微镜头或光影变化。不是每张图都要同强度运动；先检查光点是否落在合理位置。
- 人物素材与技术画面交替出现，避免中段只剩产品目录。素材不必全部使用，但应核对用户特别重视的画面是否被遗漏。
- 参照作品可以借鉴叙事和节奏，不必照搬造型；不能播放的参考应换成可访问的来源，不声称已看完未实际观看的内容。

## 五、音乐、试听与版本管理

- 先画情绪曲线，如悬念 → 危机 → 转机 → 推进 → 高潮 → 回望。音乐、镜头和字幕的关键变化共同服务故事。
- 先用临时音乐验证节奏，清楚标注试听性质；不要把程序生成的节奏草稿当作已完成的配乐。增加层次要先保证清晰，用户觉得混乱时回到已认可的版本。
- 保存用户认可的版本与对比版本，避免覆盖。检查音乐的时长、音量、峰值、开头和结尾；完整听审节拍、转场、断音与音效是否抢字幕注意力。
- 对最终使用的音乐和图像核实授权及使用条件；用户提供不自动代表可公开商用。

## 六、Remotion 实施与验收

1. 每个镜头应有清晰的时间范围和名字；字幕与画面在同一镜头内方便调整。使用统一画幅、帧率、字体和素材路径，动画由时间线驱动。
2. 保留小样、全片预览、素材索引和可复用工程。项目素材、成片、缓存、凭据及大型依赖是否进入 Git，由用途和授权决定；公开仓库默认不上传未经许可的媒体。
3. 预览阶段检查画面构图、字幕换行、遮挡、转场、人物比例、效果位置、首尾；全片逐段听看，不以抽帧或能播放代替人工审听。
4. 最终导出前确认分辨率、比例、时长、字幕、引用、音乐及素材使用条件；检查输出的视频与音轨、完整解码、文件大小和实际播放。
5. 上采样到 1080p 不等于原素材变高清，应如实说明来源分辨率和视觉限制。工程预览的音量处理应与导出文件保持一致，避免两个版本听起来不同。
6. 输出文件应版本清晰、不覆盖已确认成片，并记录项目目录、输出目录、修改内容、验证结果与仍待解决的问题。

## 本次项目的实际教训（2026-11-22）

- 用户的三张拼图是打包素材，后来强调彩色漫画画风；拆出约 39 个素材（含两个背景），独立参考照片不等于高清漫画原图。原始画面尺寸有限。
- WorkBuddy 的首次检索给出了素材线索；后续补充消息被排队为第二次搜索，造成重复工作。分配任务时写清范围、只读要求、停止条件和交付格式；追踪状态，补充线索前确认是否会启动新任务。
- 初版把部分图片和字幕当作统一卡片，用户指出字体不统一、部分人物图遗漏、屏幕效果太弱，以及后续配乐叠加混乱。改进应围绕具体反馈，保留已认可字体、素材、音乐版本，而非无差别叠特效。
- 三位人物的评价是在黄仁勋卸任后的公开讨论中出现，视频采用中文摘译；必须保留发言人、时间和原始报道，以免把引语说成完整语境。三张人物图后来统一成漫画风，成片仍需结合实际发布用途审查素材来源。
- 项目产生过多个试听音轨、检查版和成片；文件完整解码证明技术可读，不证明音乐、字幕、画风和事实都经过完整人工验收。此次未记录整片逐秒人工听审结论。

## 可复用开工提示词

> 我想制作一支【题材／人物】短片，用于【平台】，时长约【时长】，画幅【比例】，采用【旁白方式】。我的目标受众是【受众】，希望观众感受到【情绪】，看完记住【核心信息】。已有素材位于【位置】，它们的作用是【风格参考／原始素材／成片素材】；预算或限制是【限制】。请先核对既有决定和素材，查证重要事实，提出故事线、视觉方向与配乐情绪；在我确认前，只做已授权的素材处理。确认后先制作短声画小样，待反馈后再扩展全片，记录来源和版本，正式导出前检查画面、字幕、音乐和文件完整性。
