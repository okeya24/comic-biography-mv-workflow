# 漫画人物传记 MV 制作方案｜Comic Biography Video Workflow

一套可复用的**动态漫画人物传记视频制作流程**，涵盖素材拆分、人物事实核对、漫画风格统一、分镜与字幕设计、背景音乐、Remotion 预览和成片验收。适合制作人物故事、品牌创始人故事、科技发展史和漫画风格短视频。

A practical workflow for creating comic-style biography videos and motion-comic music videos, from research and storyboard to Remotion preview and delivery.

## 从哪里开始

**[阅读完整制作方案和可复制的开工提示词](docs/漫画人物传记MV制作方案.md)**

流程按实际项目调整，不限定时长或画幅。案例使用 90 秒、16:9、无口播的字幕加背景音乐形式。

## 制作流程

1. **明确目标**：确定受众、人物故事、画幅、时长、风格和授权范围。
2. **核对事实与素材**：查证年份、引语和事件；拆分拼图，建立来源与编号索引。
3. **设计声画**：用分镜、漫画字幕、局部动态和音乐情绪共同讲故事。
4. **先看短样片**：用一小段验证风格、阅读时间和节奏，再扩展全片。
5. **检查与交付**：核对素材授权、字幕、画面、音乐和输出文件的完整性。

## 常见问题

**没有口播也能讲清楚人物故事吗？** 可以：字幕交代关键事实，画面表达处境，音乐承接情绪。先检查观众能否读懂，再调整特效。

**已有多张漫画拼图，如何用于视频？** 按实际画面边界拆分，保留原图、编号和来源；检查人物、文字和尺寸，避免误裁。

**如何统一 AI 漫画人物风格？** 先选定视觉参考，再检查人物辨识度、线条、配色和构图；保留原始素材，避免将重绘画面当成历史照片。
